# Apprentice asset generation

Method: the built-in `image_gen.imagegen` tool, followed by normal runtime atlas import and procedural animation in Canvas2D. No local diffusion model or Python bitmap editing was used.

Final source: `assets/remaster/apprentice-motion.png` (1774 × 887). Generated source retained at `/Users/loganchambers/.codex/generated_images/01a0c156-417b-7c50-b73f-a17252c83043/exec-08c9b293-bdd9-457d-aded-a34316be8391.png` on the authoring machine. This is an atlas source with a magenta production matte; `src/render/apprenticeAtlas.ts` removes that matte at load time.

The first generation used a checker matte and some tools extended across nominal cells. The revision below corrected the matte and complete tool silhouettes. The importer additionally segments connected characters, ensuring an entire wrench stays with its owner even if it exceeds a nominal grid boundary. The original runtime source is replaced by the revised asset; the earlier generation remains in the tool output directory.

## Final edit prompt

> Repair this production sprite animation atlas. Keep these SAME FOUR apprentice plumbers and the high quality cartoon tower-defense painted style. EXACTLY 8 columns by 4 rows, 32 isolated full-body poses. Row1 red beard green shirt red wrench. Row2 dark skin blue shirt steel hammer. Row3 brown hair orange shirt silver adjustable wrench. Row4 blond blue overalls copper pipe. Frames left to right: idle, left stride, passing stride, right stride, attack anticipation tool raised behind head, CONTACT tool swung fully forward, low follow-through, recovered idle. CRITICAL TECHNICAL REQUIREMENT: every ENTIRE person AND every ENTIRE tool must fit COMPLETELY INSIDE ITS OWN rectangular cell, with LARGE clear empty gutters between all cells. No tool extends into any neighboring cell; no disconnected fragments anywhere. Shrink the characters if needed so the widest horizontal contact swing including tool has at least 15% empty horizontal margin at both edges of the cell. Each character's feet have an identical anchor within every cell. Provide generous extra space on right for tools at contact. Every tool must remain attached to a hand. Make the 3 walk poses distinct with clear alternating legs and arms. Preserve face/clothing/tool identity across poses. Uniform SOLID PURE MAGENTA #ff00ff background, absolutely NO checkerboard and no decorative shadows on background; this background will be keyed out by the engine. Do not draw any cell borders, lines, words, labels or grid marks. Wide 2:1 aspect ratio. 32 small characters in 32 generous roomy cells. Frame gutters and intact tools are more important than filling the canvas.

The art-board screenshot and motion recording in this directory show the actual runtime result. The walk cycle uses the painted idle silhouette with a continuous mesh gait, avoiding repeated near-identical generated stride frames. Existing tower atlases are retained and enhanced with animated Canvas mechanisms and material details.
