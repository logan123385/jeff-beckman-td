# Painted adventure presentation

Original assets generated with the built-in image generation tool. No reference image or existing commercial-game art was supplied. Three generations; JPEG encoding at quality 91 preserves the original compositions for delivery. Gameplay routes, actors, UI, and effects are rendered separately.

Assets: `assets/cinematic/environments.jpg` (four tiles), `assets/cinematic/waterworks-keyart.jpg`, `assets/cinematic/beckman-county.jpg`.

The direction combines painterly jade environments, copper machinery, warm brass menus, opaque continuous character poses, material-specific projectiles, restrained contact lighting, and map-specific atmosphere. Visual clocks follow simulation time; reduced-motion preferences disable camera shake and decorative menu motion.
