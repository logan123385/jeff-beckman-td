# Playable hero art prompts

Generated with the built-in image generation tool. User photos guided the faces, clothing, and Mike's blue/cream truck. Reference-bound drafts returned opaque checkerboards; final renders used the described likenesses with real transparency. PNG masters and optimized WebP runtime atlases are kept together in `assets/remaster`. No company logos or lettering are used on the truck.

Each atlas has 8 columns and 3 rows: movement, attack, and a signature cast. Runtime connected-actor extraction preserves overhanging limbs and weapons while retaining a fixed animation anchor. All five final masters have a real alpha channel.
